## 🤖 How I work with AI

I build with AI, but I verify what it produces — that's the part that counts.

On **코테독촉기** I kept an honest record of an AI-assisted build: I added complexity that
wasn't needed, it caused bugs, and measuring it proved the complexity was never justified.
I wrote down what went wrong more carefully than what went right.

→ [docs/기록.md](https://github.com/Layla7120/code_test_reminder_server/blob/main/docs/%EA%B8%B0%EB%A1%9D.md)

> Reading AI output critically — spotting the wrong abstraction, the missing test, the
> performance cliff — is the skill I'm building.
